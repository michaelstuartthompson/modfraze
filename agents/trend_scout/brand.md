# ModFraze trend criteria — WORKING HYPOTHESIS, v0

**Status: unproven.** Michael has not settled on a niche. This file is
deliberately wide right now, and it is meant to *narrow over time* based on
what actually sells and what he actually chooses to design.

Edit this file freely. It is the agent's taste, and it is the highest-leverage
thing you control. When the agent surfaces something wrong, the fix almost
always belongs here rather than in the code.

---

## What ModFraze is (confirmed)

Maximalist abstract graphic design, sold digitally and on drop-shipped merch.
Existing products came from a design-practice exercise using AI-generated
nonsense phrases — *Passive Aggression*, *Regret Concierge*, *Read Receipt*,
*Side Eye*, *Things You Wish You'd Said*, *Reality Check*, *Technicality*.

Those were practice, not positioning. They stay in the catalog as evergreen
filler alongside trend-driven pieces. **Do not treat them as proof of a niche.**

## What ModFraze might be (untested hypotheses)

Cast a wide net across these until sales data narrows it. Tag each shortlist
item with which hypothesis it serves so patterns become visible over time.

- **H1 — Social friction.** Naming an unspoken interpersonal dynamic. The
  "quiet quitting" / "beige flag" / "loud budgeting" shape. Closest to the
  existing catalog, but that's inheritance, not evidence.
- **H2 — Internet-native moments.** Phrases that emerge from a specific online
  event and stay legible for a season.
- **H3 — Work and money.** Employment, burnout, cost-of-living language. High
  merch conversion historically; crowded.
- **H4 — Subculture identity.** Niche-community in-language where the buyer
  signals membership. Smaller audiences, much higher conversion.
- **H5 — Pure aesthetic.** No phrase at all; a visual trend (color, motif,
  era revival) that suits maximalist abstract work. The only hypothesis where
  the trend is visual rather than verbal — worth testing precisely because
  it plays to the actual art skill.

Report against all five. Note when a hypothesis produces nothing for weeks;
that is data too.

## A trend qualifies if

- It is compressible to something wearable — 1-4 words, or a visual motif
- It has appeared on at least two different platforms
- It is early: rising, not yet named by mainstream media
- It works as maximalist abstract design, not literal illustration
- It is still legible in 6 weeks, when the merch actually ships

## A trend does NOT qualify if

- It is news, a disaster, a death, an election, or anything tragic
- It is a sports score, weather event, or scheduled recurring event
- It is a specific brand, celebrity, or IP — trademark risk, no exceptions
- It is a platform artifact ("Show HN", "Weekly discussion thread", "AITA")
- It is already saturated on Etsy/Amazon — if it's on a shirt, you're late
- It requires explaining. If the joke needs context, it doesn't sell

## Timing

Roughly 1-2 weeks from concept to live listing. Target trends estimated 2-8
weeks from peak. A trend already at peak is a miss.

## Output preferences

While the niche is unsettled, **favor variety over consistency.** Deliberately
include one shortlist item per run that does NOT resemble the existing catalog.
The goal for the next few months is to find the niche, not to serve an assumed
one — and an agent that only ever surfaces what you already make will lock in
a guess you never tested.
